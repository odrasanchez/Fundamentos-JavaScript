# Javascript: JavaScript: Introductory Exercises
## About It
>This repository contains a collection of JavaScript exercises and personal projects compiled from various sources, primarily free online courses and resources.
>
>The purpose of this repository is to serve as practice material for those who are new to JavaScript or want to reinforce their knowledge with practical examples. Some exercises are intentionally left incomplete so users can finish them and reinforce their learning.
>
>Additionally, several code snippets include comments and annotations that explain adjustments, recommendations, and key concepts about the language's use, providing a more didactic guide and facilitating understanding during the learning process.
>

## Configurations and use 🚀
You only need a modern web browser that supports JavaScript to use the files in this repository. Examples of such browsers include:
  * Google Chrome 🟢
  * Mozilla Firefox 🦊
  * Microsoft Edge 💻
  * Safari 🍎

There is no traditional installation process required. Simply download the repository to your computer. There are two ways to do this:
1. Clone the repository using Git: ```git clone https://github.com/odrasanchezdev/javascript-essentials```
2. Download the ZIP file directly from the repository's main page on GitHub.

<br>
<b>▶️ How to run the exercises</b>

Once you have the files on your machine:
1. Navigate to the folder containing the exercise or project you want to review.
2. Open the corresponding HTML file by double-clicking on it or dragging it to your browser window.
3. The JavaScript code will run automatically in the browser.
4. You can then edit the code with your preferred editor, such as Visual Studio Code, Sublime Text, or Notepad++, to complete the exercises or experiment.

💡 *Tip*: Some files may include unfinished or commented-out sections of code intended for users to complete and practice with.
